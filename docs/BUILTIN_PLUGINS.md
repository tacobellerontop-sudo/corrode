# Built-in plugins

Corrode ships with 200 plugins. All of them are off until you turn them on in
**User Settings > Corrode > Plugins**, where they are sorted into groups by what they do.

This file is generated by `node scripts/list-plugins.mjs`; don't edit it by hand.

## Filters and Muting

| **Strip Incoming Stickers** | Removes stickers from messages you receive, so they never load. |

## Privacy and Safety

Tracking, risky links and keeping your screen private.

| Plugin | What it does |
| --- | --- |
| **Blur When Unfocused** | Blurs Discord whenever its window isn't the one you're using, so people glancing at your screen can't read it. |
| **Clear URLs** | Removes tracking parameters (utm_source, fbclid, si and so on) from links you send. |
| **Confirm External Links** | Asks before opening a link from chat, showing the real address. Sites you trust open straight away. |
| **Masked Link Warning** | Marks links whose text looks like one address but which actually lead somewhere else. |
| **No Tracking** | Blocks the analytics and crash reports Discord's app sends about what you click and do. |
| **Panic Key** | Press a shortcut to cover Discord with a blank screen and silence its media at once. Press it again to come back. |
| **Privacy Blur** | Press a shortcut to blur names, avatars and message text, for screenshots and screen sharing. Hover something to read it. |
| **Scam Link Warning** | Warns you about links that imitate Discord or Steam addresses, a common way accounts get stolen. |
| **Silent Typing** | Stops Discord from telling others that you're typing. |
